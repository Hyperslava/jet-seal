# Тесты «Реактивного тюленя»

Тесты написаны по `TEST_CASES.md` и `SPEC.md` (36 тест-кейсов: 32 модульных, 4 сценарных). Используется стандартный `unittest`.

## Как запустить

Из корня репозитория:

```bash
python -m unittest discover -s tests -t . -v
```

## Что в папке

| Файл | Содержание |
|---|---|
| `test_jet_seal.py` | Модульные тесты TC-01…TC-32 по схеме AAA (Arrange / Act / Assert): конструктор, `move`, `dive`, `surface`, `can_overcome`, `calculate_energy`, `refuel`, `damage_fins` / `repair_fins`, `get_status` и иерархия исключений. Проверки с несколькими входами сделаны через `subTest`. |
| `test_scenarios.py` | Сценарные тесты TC-33…TC-36 по схеме Given / When / Then: «Шторм у Рифа Трёх Братьев», «Побег из пересохшей лагуны», «Контрабанда через дамбу», «Выход на берег с глубины». Каждый тест проходит сценарий из раздела 4.2 ТЗ шаг за шагом. |
| `pilot.py` | Класс `Pilot` — капитан тюленя. Скрывает вызовы `JetSeal` за действиями на доменном языке (`плыть`, `ползти`, `нырнуть`, `всплыть`, `преодолеть`, `заправиться` и т. д.). Используется в сценарных тестах. |
| `__init__.py` | Пустой файл. Делает `tests` пакетом, чтобы работали импорты и поиск тестов. |

В имени и докстринге каждого теста указан ID из `TEST_CASES.md` (например, `test_TC_14_dive_success`) - тест легко найти по таблице трассируемости.
